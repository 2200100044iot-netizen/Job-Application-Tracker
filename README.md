# Job Application Tracker

A responsive job application management dashboard built with React and TypeScript.

## Features
- Add and delete applications
- Search and filter by status
- Application statistics
- LocalStorage persistence
- Responsive desktop/mobile UI
- Reusable component-oriented React structure
- Accessible form controls and buttons

## Tech Stack
React · TypeScript · Vite · Lucide React · CSS

## Run locally
```bash
npm install
npm run dev
```

## Why this project
Designed as a frontend engineering project for demonstrating client-side state, responsive UI, browser storage, filtering, forms, and component-driven development.
